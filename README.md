# TP Bases de données avancées

Ce dépôt centralise les différents travaux pratiques réalisés dans le cadre du cours de **Bases de données avancées**. Chaque dossier correspond à une technologie ou à un projet précis.

## Contenu

| Dossier | Travail |
| --- | --- |
| `PostgreSql-Projet1` | Travaux pratiques avec PostgreSQL |
| `Neo4j-Projet2` | Projet basé sur Neo4j |
| `Rstudio-Projet3` | Analyse de données avec RStudio |

Les dossiers sont organisés pour ajouter progressivement les scripts, les données, les rapports et les résultats produits durant le TP.

## Organisation du travail

- Chaque membre travaille sur sa partie dans le dossier correspondant.
- Les fichiers doivent être nommés de manière claire.
- Les avancées sont enregistrées régulièrement avec des messages de commit explicites.
- Les rapports, données sources et documents importants sont conservés dans le dossier du projet concerné.
